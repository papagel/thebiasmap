# thebiasmap.com

The built Cognitive Bias Explorer: an interactive map of 188 cognitive biases, in English and Greek,
served by GitHub Pages at [thebiasmap.com](https://thebiasmap.com).

Everything here is generated. Don't edit it by hand: change the source in the
`cognitive-bias` repository (next to this one), run `python3 build.py`, then commit and push this repo.
